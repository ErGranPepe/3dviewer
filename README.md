# Parrilla Neuronal

Sitio estático (sin paso de compilación): Vercel sirve estos archivos tal cual.

- `config.js`: ID de AdSense, bloques de anuncio, contacto y patrocinadores de las vallas.
- `a/`, `t/`: código y texturas con hash en el nombre (caché de un año).
- Si configuras AdSense, añade `ads.txt` con la línea que te da Google.

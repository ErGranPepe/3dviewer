# Parrilla Neuronal

Simulador de Fórmula 1 que funciona entero en el navegador (un solo `index.html`, sin instalar nada).

- Los 16 circuitos reales del calendario 2024 (TUM racetrack-database + telemetría oficial de 2024).
- Física del coche calibrada con vueltas reales (error medio de tiempo por vuelta ≈ 3 %).
- Pilotos de IA entrenados por imitación, estrategia, safety car, lluvia, muro de boxes y modo temporada.
- Gráficos con Three.js r180, oclusión ambiental N8AO, cielos HDR de Poly Haven (CC0) y realización de TV con repeticiones y narración.

Despliegue estático: Vercel sirve `index.html` tal cual (sin paso de compilación).
